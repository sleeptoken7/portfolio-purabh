# Portfolio Purabh

This is a professional, high-impact portfolio website built for Purabh Singh.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion
- **Content:** MDX (for deep-dive case studies)
- **Icons:** Lucide React
- **Hosting:** Optimized for Vercel

## Key Features
- **Bento Box Hub:** A high-density, professional landing page.
- **Deep-Dive Case Studies:** Full rendering of technical READMEs using MDX.
- **Impact-Driven Narrative:** Focused on business value and technical leadership.
- **Dark Mode Terminal Aesthetic:** Signals technical depth and modern engineering.

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`

## Deployment
Push this folder to a new GitHub repository and connect it to Vercel. It will be live 24/7/365 for free.
